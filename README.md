Ember & Olive Restaurant Website
A responsive restaurant website assignment built with HTML, CSS and JavaScript.

Pages
index.html — home and featured dishes
about.html — story, mission and values
menu.html — six sample products and prices
contact.html — sample contact details and validated form
Technologies demonstrated
Semantic HTML, external CSS, Flexbox/Grid layouts, responsive media queries, external JavaScript, mobile navigation, form validation, and accessible form labels.

Run locally
Open index.html in your browser or use the VS Code Live Server extension.

Demo notes
Menu prices and contact details are sample content. Replace them as appropriate. The form performs front-end validation only; it does not send messages because no backend/form service is connected. Images and fonts load from external providers, so internet access is needed for them.

GitHub and deployment
Create a repository, commit the project files regularly, and deploy the project root as a static site on Netlify or Render. Include both the repository URL and live URL in your submission.
